# Vera

**Real connection, daily.**

A mobile app that gives you one simple task each day — do something real with another human.

## The Idea

1. Wake up → get a task ("Have coffee with someone ☕")
2. Do the task IRL with a real person
3. Share your Vera link with them
4. Task complete ✅
5. They might sign up → new user → they get a task → cycle continues

## Why It Works

- Forces real human interaction
- Can't complete alone — need another person
- Viral by design (every completion = link shared)
- Simple, no overthinking
- Anti-loneliness in app form
