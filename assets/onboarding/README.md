# Onboarding Illustrations

Add your Midjourney-generated images here:

- `slide-1.png` - Welcome / Two people connecting
- `slide-2.png` - Share Connection / Showing phone with link
- `slide-3.png` - Get Started / Ready to begin

## Recommended specs:
- **Size:** 1024x1024px (will be scaled to fit)
- **Format:** PNG with transparent background (or white)
- **Style:** Bold black outlines, flat colors, chibi proportions

After adding images, uncomment the `<Image>` component in `App.js` and remove the placeholder view.
